🧪 Dataset & Architecture Info

  • Dataset Source: UCI Phishing Websites & PhishTank Corpus
  • Total Samples: 3,500 Balanced Vectors
  • Train / Test Split: 80% Training / 20% Testing
  • Feature Space: 16 Extracted Lexical & Structural Features
  • Classifier Model: RandomForestClassifier(n_estimators=100)
  • Model Serialization: Joblib Binary File (.pkl)
  • Inference Speed: ~12ms per URL scan
