Privacy Policy

Enterprise data handling, telemetry isolation, and cryptographic storage standards.

1. Information We Collect

When you utilize PhishGuard AI systems, we process:

  • Account Credentials: Sanitized analyst username and cryptographic PBKDF2 salted hash representations.
  • Telemetry Targets: Submitted URLs, sanitized email headers, and SMS test snippets.
  • Audit History: Heuristic risk scores, timestamp logs, and execution confidence values.
  • Network Bounds: Session tokens and rate limiting trackers to safeguard against automated flooding.

2. How We Use Telemetry

Collected metrics serve exclusively for:

  • Validating active analyst sessions via signed bearer tokens.
  • Evaluating multi-feature threat matrices across Random Forest and NLP classifiers.
  • Generating persistent dashboard metrics and SOC incident history.
  • Mitigating brute-force intrusions and rate-limit violations.

3. External Intelligence Interfaces

To deliver comprehensive multi-engine corroboration, external lookups query:

  • VirusTotal Engine: Multi-vendor malware verdict correlation.
  • Google Safe Browsing: Blacklist corroboration for zero-day distribution domains.
  • DNS-over-HTTPS & RDAP: Authoritative name servers and domain age extraction.

4. Cryptographic Storage & Isolation

User passwords undergo PBKDF2 hashing with high iteration counts and individual salts. Local sessions use modern web security headers, HTTP strict transport standards, and zero plaintext credential logging.

For privacy queries, data purge requests, or security disclosures: privacy@phishguard.ai.
